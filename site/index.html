isISOMatch accepts a string only when it matches the selected ISO 8601 shape and every field is a real calendar value. Unlike Date.parse, nothing is guessed, coerced, or filled in.

Arithmetic — top-level core

Calendar-field math is delegated to Temporal.PlainDate, so month-end overflow clamps rather than spilling: try addMonths on 2023-01-31. Time-of-day is preserved untouched.

Comparison & difference

isBefore/isAfter/isEqual compare full instants; the isSame* family compares local calendar fields and ignores time-of-day.

Served as static assets from Cloudflare Workers. The page imports ./lib/strict.js and ./lib/index.js — the package's own compiled output, unmodified — directly as ES modules. No bundler, no polyfill, no network calls after load.
